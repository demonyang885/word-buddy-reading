# 單詞星球與中文字星球

一個適合 iPad Safari 的兒童認讀網頁。孩子必須親口讀出畫面上的單詞或字詞；系統透過瀏覽器語音識別判定讀音，按鈕本身不會把項目記為「會讀」。

- 英文認詞：<https://demonyang885.github.io/word-buddy-reading/>
- 中文認字：<https://demonyang885.github.io/word-buddy-reading/chinese.html>

## 功能

- **認讀**：可手動聽標準發音，再由孩子自己讀出；識別正確後才記為會讀。
- **挑戰**：不先播放答案，孩子看到項目後獨立讀出。
- **鞏固**：錯誤項目必須連續讀對兩次才會移出待鞏固清單。
- **逐項檔案**：保存每項的嘗試次數、正確次數、系統最後聽到的內容和練習時間。
- **斷點續學**：重新整理、關閉 Safari 或再次開啟網址後，接續上次範圍、模式和位置。
- **檔案備份**：支援匯出和恢復 JSON 學習檔案；中英文檔案及進度完全分開。

## 中文認字資料庫

中文資料保存在 `chinese-words.js`，共 12 個教材頁組、548 條原始記錄；精確去重後共有 493 個字詞。頁組來源與原始次序均有保留，相同字詞在不同頁出現時共用學習進度。

中文頁可選擇：

- 第一份詞表：第1、2、3、4、5、6、7、8–10頁
- 第二份詞表（Scanned Document 10.56.49 AM）：第1–2、3–5、6–8、9–10頁

語音預設為香港粵語 `zh-HK`，設定中可切換至繁體普通話 `zh-TW`。中文只接受完整字詞匹配，不使用子句包含判定；`什麼／甚麼`、`書裡／書裏`等已明確設定可接受字形。

## iPad 使用要求

1. 使用 **Safari** 開啟 GitHub Pages 的 HTTPS 網址。
2. 在 iPad 設定中啟用 Siri 或聽寫。
3. 第一次按「開始認讀」時，允許網頁使用咪高峰和語音識別。

Safari 的網頁語音識別由裝置的 Siri 語音引擎提供。在微信、其他應用程式內置瀏覽器或不安全的 HTTP 網址開啟時，語音識別可能無法使用。孤立單字中的同音字亦無法只靠聲音完全區分，因此真機測試仍然必要。

## 學習記錄

英文與中文使用不同的瀏覽器儲存空間，互不覆蓋。記錄在同一 Safari 與同一網址中可以於重新整理後恢復；更換裝置或清除網站資料前，請先從「學習檔案」匯出備份。

學習記錄和語音識別結果不會寫入 GitHub 倉庫。

## 本機預覽

```bash
python3 -m http.server 8000
```

本機 HTTP 網址可檢查版面和學習檔案；正式咪高峰語音識別請使用 GitHub Pages 的 HTTPS 網址。
