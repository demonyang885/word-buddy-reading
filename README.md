# 单词星球（Word Buddy）

一个适合 iPad Safari 的儿童英文单词认读网页。孩子必须亲口读出单词；系统通过浏览器语音识别判定是否读对，点击按钮本身不会记为“会读”。

在线学习地址：<https://demonyang885.github.io/word-buddy-reading/>

## 功能

- **认读**：可先听标准发音，再由孩子读出单词；识别正确后才记为会读。
- **挑战**：不先播放答案，孩子看到单词后独立读出。
- **巩固**：错词必须连续读对两次才会移出错词本。
- **逐词档案**：保存每个单词的尝试次数、正确次数、系统最后听到的内容和练习时间。
- **断点续学**：刷新、关闭 Safari 或重新打开网址后，从上次的模式和单词继续。
- **档案备份**：支持导出和恢复 JSON 学习档案。

## iPad 使用要求

1. 使用 **Safari** 打开 GitHub Pages 的 HTTPS 地址。
2. 在 iPad 设置中开启 Siri 或听写。
3. 第一次点击“开始认读”时，允许网页使用麦克风和语音识别。

Safari 的网页语音识别由设备的 Siri 语音引擎提供。若在微信、其他应用内置浏览器或不安全的 HTTP 地址打开，语音识别可能不可用。

## 学习记录保存

逐词档案保存在当前浏览器的本地存储中，刷新、退出 Safari 和重新启动 iPad不会清除。Safari 网站数据被手动清除或更换设备时，请使用“学习档案 → 导出学习档案”备份，并在新设备上选择“恢复学习档案”。

学习记录和麦克风识别结果不会写入 GitHub 仓库。

## 更新词库

所有单词都在 `words.js` 的 `window.WORD_DATABASE` 数组中。替换数组内容后重新发布即可，无需修改其他文件。

目前放入了 48 个儿童常用词作为功能验证数据。收到原始 `IMG_6355.heic` 后，可替换为图片中的精确词表。

## 本地预览

```bash
python3 -m http.server 8000
```

本地 HTTP 地址可查看布局和学习档案，但正式的麦克风语音识别请使用 GitHub Pages 的 HTTPS 地址。
